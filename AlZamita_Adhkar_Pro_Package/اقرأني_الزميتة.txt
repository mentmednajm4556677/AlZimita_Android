الزميتة للأذكار - إصدار Pro
===========================

التشغيل على Windows:
1) ضع ملف AlZamita_Adhkar_Pro.py في مجلد المشروع.
2) افتح VS Code داخل المجلد.
3) افتح Terminal واكتب:
   python AlZamita_Adhkar_Pro.py

المتطلبات:
- Python 3
- Tkinter و SQLite (مرفقان عادة مع تثبيت Python على Windows)
- لا يحتاج التطبيق إلى تثبيت مكتبات خارجية.

البيانات:
- ينشئ التطبيق ملف adhkar_data.db لحفظ الإعدادات والمفضلة والعداد.
- ينشئ ملف tasbeeh_backup.json كنسخة احتياطية للعداد.
- احتفظ بهذين الملفين إذا أردت الاحتفاظ ببياناتك.
